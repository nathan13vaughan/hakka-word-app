# Hakka Word of the Day · 客家話

A tiny local app that teaches you one new Hakka Chinese word every day.
Each day's word is generated by Claude — Chinese characters, Pha̍k-fa-sṳ
romanization (Sixian dialect), a plain-English pronunciation guide, definition,
example sentence, Mandarin equivalent, and a short cultural note. Every word is
saved to `data/words.json`, so your history builds up over time and words are
never repeated.

## How it works

- `server.js` — a zero-dependency Node server. It serves the page and, on the
  first visit each day, runs the **Claude Code CLI headlessly**
  (`claude -p --output-format json`) to generate a new word. This uses your
  existing Claude login — no API key, no extra setup.
- `public/` — the word-of-the-day page (today's word + full history).
- `data/words.json` — every word you've learned. This is your review list;
  back it up if you care about it.

## Running it

Double-click `start-hakka.cmd`, or run:

```
node server.js
```

then open http://localhost:3456. Requires Node.js (no `npm install` needed).

## One-time setup: Claude CLI login

Word generation runs through the Claude CLI at `%USERPROFILE%\.local\bin\claude.exe`.
If its login has expired you'll see a friendly error in the app — fix it by
opening a terminal, running `claude`, and logging in when prompted. If your
`claude` executable lives somewhere else, set the `HAKKA_CLAUDE_PATH`
environment variable to its full path.

Generation uses **Sonnet** by default for speed. Set `HAKKA_CLAUDE_MODEL`
(e.g. `opus`, `haiku`) to use a different model.

## iPhone home-screen widget

The widget runs inside [Scriptable](https://apps.apple.com/app/scriptable/id1405459188)
(free) and shows the latest word on your home screen, with offline caching for
when your PC is asleep. Setup:

1. **On your PC, once, in an *administrator* PowerShell** — allow the phone to
   reach the server through Windows Firewall:
   `netsh advfirewall firewall add rule name="Hakka Word Server" dir=in action=allow protocol=TCP localport=3456`
2. **On your iPhone** (same Wi-Fi, server running): install Scriptable, then
   open `http://192.168.50.46:3456/hakka-widget.js` in Safari, select all the
   text and copy it.
3. In Scriptable: **+** → paste → name it "Hakka Word".
4. Long-press your home screen → **Edit** → **Add Widget** → Scriptable →
   choose a size → tap the widget → set **Script** to "Hakka Word".

The widget checks `/api/latest` (which never blocks — it returns the newest
stored word instantly and quietly starts today's generation in the background
if needed) and caches the last word on-device. Tapping the widget opens the
web app. If your PC's LAN IP changes, edit the `SERVER` line at the top of
[public/hakka-widget.js](public/hakka-widget.js) and re-copy it to your phone.

### Working from anywhere via GitHub

The widget's preferred source is the public GitHub repo
(`nathan13vaughan/hakka-word-app`), which works on any network with the PC
asleep — no tokens needed. After each generated word the server auto-commits
and pushes `data/words.json` + `data/latest.json` (skipped if no `origin`
remote), and while the server runs it auto-generates each day's word after
7 a.m.

The repo also serves a **GitHub Pages mirror of the app** at
<https://nathan13vaughan.github.io/hakka-word-app/> — the root `index.html`
is a read-only viewer of the synced words, and tapping the home-screen
widget opens it. Since generation happens on the PC, the mirror always shows
the last word that was pushed.

## API

| Endpoint | Method | Purpose |
| --- | --- | --- |
| `/api/today` | GET | Today's word (generates one if none exists yet) |
| `/api/new` | POST | Force-generate an extra word right now |
| `/api/history` | GET | All learned words, newest first |

## Notes

- Dialect: Sixian (四縣) Hakka as spoken in Taiwan, romanized in Pha̍k-fa-sṳ.
- The server rotates through ~30 topic themes so daily words stay varied, and
  it passes your full word history to Claude so nothing repeats.
- Generation takes anywhere from ~15 seconds to a couple of minutes; the page
  shows a loading state while it works.
